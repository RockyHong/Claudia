# GAP-002 — window identity is unverified for shared windows and non-Windows-Terminal hosts

**Logged:** 2026-09-10 · **Source:** two live probes run while fixing BUG-003 (resolved in `6802527`) — both cases were out of reach at measurement time
**Problem:** Session-to-terminal-window resolution now anchors on the ancestor owning a `PseudoConsoleWindow` and takes that window's parent ([Sessions § Window linking](../specs/sessions.md#window-linking)). That was measured correct for five live sessions in five separate Windows Terminal windows, but two situations were never observed, because neither existed on the machine during either probe and creating them was outside read-only scope:

1. **Two sessions sharing one window** — multiple tabs, or a split pane. Structurally both should resolve to the same terminal window handle, which the contract permits (linking never treats a handle as exclusive) — but it is untested, and it is the one case where the per-window identity degenerates back toward the ambiguity BUG-003 removed. Closing one tab of a shared window is the specific path worth checking: the window survives, so only the dead session's `claude.exe` liveness check should remove its card.
2. **Terminals other than Windows Terminal** — ConEmu, mintty, Alacritty, WezTerm and the rest of the name list the walk carries. None was running. A host that does not use a ConPTY pseudo-console window may resolve nothing, which degrades to an unlinked session (admitted, no alerts) rather than a wrong window.

Nesting depth >= 2 is covered by unit test only; no live nested session was measured.

**Area:** `packages/server/src/pid-ancestry.js` (`resolveTerminalWindow`), `packages/server/src/index.js` (auto-link + liveness sweep), [`docs/specs/sessions.md`](../specs/sessions.md) § Window linking / § Lifecycle
**Prior:** measuring case 1 needs a human to open a second tab in an existing Windows Terminal window and run a session in it — a probe cannot create the case without mutating the user's windows. Case 2 needs one of the other terminals installed and running.
